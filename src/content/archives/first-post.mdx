This is the first post on this site. Figured I should explain why it exists.

I've been building things for a while now — some for class, some for fun, some because I got obsessed with a particular tech stack and needed an excuse to use it. Most of them live on GitHub, buried in repos nobody sees. This site is my attempt to change that.

## why astro?

Honestly? I just wanted something fast, simple, and not React. Astro's island architecture clicked with me — ship HTML by default, hydrate only what needs it. Plus the content collections make managing projects and blog posts feel like working with a real CMS, but without the headache.

The stack is pretty boring:
- Astro for the framework
- Tailwind for styling
- TypeScript because I like my types
- GSAP for the little animations here and there

## what you'll find here

Two main sections:

**Projects** — the things I've built. Some are polished, some are held together by duct tape and hope. Each one has a writeup about what it is, why I built it, what went wrong, and what I learned.

**Archives** — this blog. Tutorials, random thoughts, things I figure out and want to remember. Might syndicate stuff from elsewhere too, but I'll always add a personal note upfront.

## what's next

More projects. More posts. Probably a redesign in six months because I'll hate the current one.

If you're building something too, feel free to reach out. Always down to chat about web dev, IoT, or why your CI pipeline is broken.
